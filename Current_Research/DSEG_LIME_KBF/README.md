# Explainable AI and knowledge based filtering for MGMT prediction

This project is part of **Anes Hadjadj’s doctoral research** on deep learning for brain MRI analysis.

It explores how knowledge-based image processing and explainable AI can support the study of MGMT prediction, with an emphasis on **predictive performance and interpretation of model decisions**.

Detailed methods, experimental results and supporting implementation will be shared **after publication**.
